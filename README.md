# Refro

Web UI for [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness). Chat, one-click tasks, skills, apps, and automations on a local dashboard.

## Run

```bash
npm install
npm run dev
```

Open http://127.0.0.1:5173/

Put `OPENROUTER_API_KEY` or `DEEPSEEK_API_KEY` in `~/.dsh/.credentials.yaml`. Do not commit keys.

## Scripts

```bash
npm run build
npm test
```
